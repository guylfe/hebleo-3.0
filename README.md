# Hebleo 3.0

Local-first development of Hebleo's human-authored Hebrew learning platform.

The product owner requested a private GitHub repository, continuous Git checkpoints, a coordinated specialist team, and a broadly scoped first working build with a local demo.

Authoritative input: [master specification](docs/MASTER_SPEC.md). The first-build scope and verification criteria are in [INITIAL_BUILD_BRIEF.md](docs/INITIAL_BUILD_BRIEF.md).

Implementation, installation, demo commands, verified features, and limitations will be documented here by the integration owner as the build progresses. This initial checkpoint contains planning artifacts; it is not yet a working application.
