Setup instructions

The JSON file connects this app to Google. It is not a lesson, spreadsheet or other learning file. Google creates the OAuth client JSON; you do not need to write it yourself.

Use one Google connection for multiple spreadsheet sources. You do not need a separate client for each Sheet. Choose the route that fits what you already have.

Route 1 · You already have an authorized client JSON

Use an existing Google Desktop or Web OAuth client file that you are authorized to use. A new client is not automatically required. Continue with “Finish here” below.

For an existing Web client, add the exact address reported by this app to that client's authorized redirect URIs. Copy it exactly; the port belongs to this running app.

Current callback: Use “Exact runtime callback” above once status loads.

Route 2 · You do not have a client JSON yet

  1. Open Google Cloud Console as guylfe@gmail.com. Select an existing project you can use, or create a project for this app.
  2. In APIs & Services → Library, find and enable both Google Sheets API and Google Drive API in that project.
  3. Open Google Auth platform → Branding. If setup has not started, choose Get Started. Enter an app name such as “Hebleo local authoring”, a support email and your contact email.
  4. Choose External as the audience. In Audience → Test users, add guylfe@gmail.com and save.
  5. In Data Access → Add or Remove Scopes, select these permissions, then save:
    • https://www.googleapis.com/auth/spreadsheets.readonly — read spreadsheets.
    • https://www.googleapis.com/auth/drive.metadata.readonly — read file metadata.
    • openid and email — identify your Google account.
  6. Open Clients → Create Client. Select Desktop app, give the client a name and create it.
  7. Download the client's JSON file to this computer. Select that downloaded file in this page's file chooser; do not paste it into chat.

Finish here · Connect this app

  1. Use Choose OAuth client JSON above to select the existing or downloaded file.
  2. Press Configure selected file securely. This configures the app; it has not connected your Google account yet.
  3. Press Connect Google, then use the displayed Open Google consent yourself link.
  4. Sign in as guylfe@gmail.com and grant the requested read-only and identity permissions. Google returns you to this app's callback.
  5. Return to this setup page and press Refresh connection status manually. Check that the account is verified and the source session is authorized.

Your client file and connection tokens go only to this local app's protected storage. They are excluded from learning content, exports and backups.

Then add the learning sources in Studio

Return to Studio to add sources, one registration per spreadsheet tab, using the same Google connection. The team prepares spreadsheet IDs, headers, grid ranges and mappings; you do not need to build source JSON. Connecting Google does not import arbitrary documents or media, or approve teaching content.
