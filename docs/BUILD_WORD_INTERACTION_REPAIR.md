Guy reported on 22 October 2026 that Build word presses lagged and that word cards worked in the saved-draft test preview while the ordinary lesson offered only Vocabulary help. Build selection/removal now updates the UI immediately and uses the existing debounced progress saver, as typing already does. Saves remain ordered, navigation flushes the latest sentence, failures retain the edited sentence and use the existing save-error feedback, and grading keeps its existing authoritative request path. Token actions also reject changes while grading is pending.

`scripts/link-illustrative-exercises.mjs` is an explicit one-time authoring helper for the nine existing illustrative exercises. Its fixed entry IDs, unpointed forms and meanings must match the existing sample entries. It adds validated complete-token occurrences using those entries' existing exact written forms. It does not infer identities during rendering or grade lookup, strip prefixes, map real curriculum content, change entries or answers, or run during startup. The separate `ב` token and hidden `בבית` entry do not acquire a fabricated card.

Publication uses existing Store validation and nested transactions. It creates a new immutable content revision and rebases the saved draft, retaining its unrelated edits and staging time; it never publishes the whole existing draft. Existing learner records, attempts, settings, old revisions and source records are conserved. Source-bound publication is refused and must follow its existing human-reviewed workflow. This helper is not a source-approval bypass.

An already-started lesson stays pinned to its previous version. The existing **Start updated lesson** action selects the new content; its documented reset of that lesson's current answers is a learner choice. Historical grades and review progress remain.
